Put your licensed web-font files here, named exactly:

  ABCROMVariable.woff2     ABC ROM Variable (Dinamo)  -> body / UI text   (css var --sans)
  Exposure-10.woff2        Exposure [-10] (205TF)     -> titles, nav, captions (css var --serif)

Optional .woff versions with the same names are used as a second choice.
Export web fonts from your font licence portal (Dinamo / 205TF) - "woff2" is the format you want.
If the files have different names, edit the two @font-face blocks at the top of styles.css.
If the fonts are installed on your own computer the page will already use them locally.
